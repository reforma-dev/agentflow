# AgentFlow

**Agent loop:** [README.md](README.md) — optional research → grill → usually `/plan` → sequential PRs (implement → `/code-review` → `/commit`) → refresh context when needed.

This repo publishes its reusable skills from `skills/`. Consuming repos install
or copy them into their own agent skills directory.

CLI source lives in `src/`. `bin/agentflow.js` is generated by
`bun run build`; edit the TypeScript source, not the bundle.
